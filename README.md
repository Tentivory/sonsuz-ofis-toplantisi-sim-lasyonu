# Sonsuz Ofis Toplantısı Simülasyonu

## Neden Bu Proje?

Çünkü hayat zaten bir toplantıdır. Bu simülasyon, o toplantıyı sonsuza kadar uzatır. Katılımcılar kaçabilir ama sen kaçamazsın.

Bilimsel olarak kanıtlanmıştır ki, ofis toplantılarının %99'u gereksizdir. Bu yazılım o %1'i de yok eder.

## Nasıl Çalışır?

```bash
python toplantı.py
```

Sonsuz döngüye girer, çıkamazsın. Ctrl+C bile çözüm değildir, çünkü toplantı devam eder.

## Özellikler

- Sonsuz süre
- Absürt konular
- Kimse konuşmaz, herkes "evet" der
- Verimlilik -100%
